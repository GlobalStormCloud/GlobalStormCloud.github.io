---
title: 13. Monitoring devices & containers
description: Open a device's detail view for connectivity, health, per-container stats, full logs, remote restart and reboot — plus a fleet summary of online, offline, and awaiting-first-boot devices.
---

Open the Devices page and select a device to see its detail view:

- Connectivity — online / offline, last seen.
- Health — RAM, disk usage, and disk health (lifetime + temperature).
- Applications & containers — each container with uptime, CPU, memory, restart count,
  and exit code.
- Full Logs — pull the real logs for any container, straight from the dashboard.
- Restart — restart a single container remotely.
- Reboot — reboot the whole device remotely.

The fleet summary at the top shows totals: how many devices are online, offline, or awaiting
first boot.
