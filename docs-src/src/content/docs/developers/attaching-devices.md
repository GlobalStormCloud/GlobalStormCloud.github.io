---
title: 11. Attaching devices to an application
description: A device runs one application at a time — attach devices from the Applications page or a device's detail page; attaching automatically detaches from any other application.
---

A device runs one application at a time. Attaching a device to an application tells the
platform that this device should run that app.

1. On the Applications page, find your app and click Manage.
2. Tick the devices you want to attach, then save.
   - Attaching a device automatically detaches it from any other application.
3. Alternatively, from a device's detail page you can select an application from the
   Application dropdown.

A newly attached device shows not installed until you deploy a build to it (next section).

:::note
While a device is still applying an attach or detach, the control is briefly locked and
shows attaching… / detaching…. This is normal — it prevents conflicting changes
while the device converges.
:::
