import { Card, CardGrid, LinkCard } from '@astrojs/starlight/components';

This documentation explains how to run devices on HurricaneOS and how to ship
your application to them: flashing a device, booting and provisioning it,
connecting a Git repository, pushing code, and deploying a build to one device
or your whole fleet.

It is written for two audiences.

<CardGrid>
	<Card title="Operators" icon="setting">
		People who prepare hardware and manage the device fleet — flashing
		disks, bulk provisioning, first boot, monitoring, and day-2 operations.
	</Card>
	<Card title="Developers" icon="laptop">
		People who write the application and push code — connecting a Git
		repository, authoring docker-compose services, building, and deploying.
	</Card>
</CardGrid>

Where a step is operator-only or developer-only, it is marked.
